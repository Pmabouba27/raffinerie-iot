Modèle de simulation — Corrélations physiques réelles
Normal

Fluctuations gaussiennes avec rappel élastique. Corrélations physiques actives : temp↑ → pression↑ (Gay-Lussac), cycle journalier ±8%.

Dégradé

Pré-signature sur 5 ticks avant anomalie franche. Débit↓ → vibration↑ (cavitation). Niveau bas → chute de débit (pompe à vide).

Anomalie

Cascade de panne : panne pompe → chute débit + surchauffe aval + vibrations. Pic brutal / dérive hors plage / panne capteur.
